# AuraRing — Next-Gen Smart Health Ring Landing Page

> A modern, ultra-high-converting, commercial-grade Single Product E-Commerce Landing Page built with pure semantic **HTML5**, modern **CSS (CSS Variables)**, **FontAwesome 6**, and **Vanilla JavaScript**.

---

## ⚡ Live Features

- **Interactive Color Switcher:** Instantly preview 4 finishes (Stealth Black, Space Silver, Rose Gold, Brushed Titanium) with animated transitions.
- **Dynamic Size Selector:** Select US ring sizes 6 to 13 with integrated Sizing Kit assurance.
- **Conversion-Optimized Bento Grid:** Feature showcase highlighting clinical sleep staging, 7-day battery life, and PPG bio-sensors.
- **Competitor Comparison Matrix:** Direct value comparison against smart watches and subscription-based smart rings.
- **Sticky Buy Bar:** Appears automatically as users scroll down for friction-free ordering.
- **Slide-Over Quick Order Drawer:** Interactive cart summary, promo code engine (`LAUNCH10`), and SSL trust badges.
- **Zero Dependencies:** Pure CSS & Vanilla JS. No React, no Vue, no Tailwind CLI, no npm build steps needed.

---

## 🚀 Quick Setup & GitHub Pages Deployment

1. **Clone or Download** this repository.
2. Open `index.html` directly in any web browser.
3. **To host free on GitHub Pages:**
   - Push to your GitHub repo.
   - Go to **Settings > Pages > Branch: main > Save**.
   - Your live URL will be active immediately.

---

## 🎨 Easy Brand Customization

Edit colors in `assets/css/style.css`:

```css
:root {
  --color-primary: #10B981;             /* Primary CTA & Glow */
  --bg-body: #090D16;                  /* Luxury Dark Slate Background */
  --font-family: 'Plus Jakarta Sans';   /* Modern Typography */
}
```
