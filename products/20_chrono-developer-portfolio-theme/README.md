# Chrono — Minimalist Developer & Consultant Portfolio Theme (SKU #20)

Production-ready modular portfolio template for principal engineers, systems architects, and technical consultants. Zero build tools or external framework lock-in.

## Included Files
- `index.html`: Semantic developer portfolio (zero third-party marketplace links inside client template).
- `assets/css/style.css`: Terminal Dark + Archival Light themes, CSS grid cards, drawer styling & 390px mobile responsive breakpoints.
- `assets/js/main.js`: Live tech stack filters (`All`, `Rust`, `Go`, `TypeScript`, `Cloud`), interactive architecture case-study drawer modal, 26x7 interactive commit activity grid (`2026`/`2025`), and advisory retainer estimator.
- `assets/images/*.svg`: 5 custom vector architecture schematics (`chrono-mark.svg`, `nexus-topology.svg`, `aegis-mesh.svg`, `wasm-sandbox.svg`, `latency-bench.svg`).
- `Access-Your-Template.html`: Illustrated quick-start & Netlify / Vercel / GitHub Pages deployment guide.
- `04_Commercial_License/Commercial-License-Certificate.txt`: Client & commercial portfolio usage license.
