AuraRing Documentation

AuraRing is an editorial Nordic e-commerce template engineered for high-conversion physical hardware, luxury wearables, and direct-to-consumer flagship product launches.

Pure Modern CSS & Vanilla JavaScript Zero dependencies, zero build steps. Fully responsive across 4K displays down to compact smartphones.

The Editorial Design System

The template pairs an editorial serif (Cormorant Garamond) with a precision geometric sans (Plus Jakarta Sans). Colors are grounded in organic Nordic sandstone and studio obsidian.

Token Name Default Hex Role
--canvas-dark #121110 Studio Basalt background
--canvas-warm #F4EFEA Warm Sandstone editorial canvas
--accent-action #1D4ED8 Royal Ultramarine conversion buttons
--accent-gold #C5A880 18K Champagne Gold highlight seals

Customizing Colors in 30 Seconds

Open assets/css/style.css. All primary tokens are located on lines 15–40:

:root {
  --canvas-dark: #121110;        /* Change background canvas */
  --accent-action: #1D4ED8;      /* Change main CTA button color */
  --accent-gold: #C5A880;        /* Change luxury accent color */
}

Free One-Click Live Hosting on GitHub Pages

To publish your live demo without paying for hosting:

  1. Create a repository on GitHub and push these files.
  2. Open Settings > Pages in your GitHub repository.
  3. Select Branch: main and click Save.
  4. Your store is instantaneously live with global HTTPS and CDN caching!

Connecting Real Payment Processors

Locate the #editorialDrawer checkout button in index.html (line ~430) and replace the button's onclick handler with your direct Stripe Checkout URL, Shopify Buy Button embed, or Lemon Squeezy checkout link.
